# P.Log — 폴스타4 전기차 주행·충전 로그 (Android Automotive OS)

폴스타4 차량 화면에서 직접 동작하는 개인용 전기차 **주행·충전 로그** 앱입니다.
USB 사이드로드로 설치하며, 외부 라이브러리 없이 플랫폼 API만으로 만들어졌습니다.

> 개인 프로젝트이며 폴스타·볼보와 무관합니다. 사용에 따른 책임은 사용자에게 있습니다.
> 이 저장소에는 **API 키가 하나도 들어 있지 않습니다.** 아래 안내대로 본인 키를 넣어 빌드하세요.

## 주요 기능

- **주행 자동 기록** — 바퀴 틱(WHEEL_TICK) 기반 거리, GPS 경로, 평균·최고 속도, 전비, 회생 회수량. 터널·지하에서도 거리가 끊기지 않습니다.
- **주행 탭** — 배터리·주행가능거리, 속도, 이번 주행 거리·전비, 실시간 전력 게이지, 충전 이후 사이클(달린 km·배터리 사용·회생 비율).
  주행 중엔 **지금 달리는 경로 라이브 지도**(전비 색), 주차 중엔 이번 주·이번 달 요약과 오늘 타임라인·주행 기록 표로 바뀝니다.
- **주행 기록 화면** — 일간/주간/월간/연간/전체 탭, 기간 요약, 출발 → 도착 동네 이름, 경로 지도(구간별 전비 색), 개인 최고 기록.
- **충전 자동 기록** — 충전 감지, kWh·요금 계산, 급속/완속 구분, 충전 속도 곡선. 주간/월간/연간/전체 탭과 급속/완속 비율 띠.
- **충전소 자동 인식** — 한국환경공단 충전소 OpenAPI로 충전소명·운영사를 식별하고 환경부 로밍 단가표로 요금 자동 계산.
  기록에서 **지도에서 충전소 직접 선택** → 다음부터 그 위치에서 자동 인식, 공식 요금표(ev.or.kr)를 앱 안에서 읽어 단가 채움.
- **주행 중 화면** — targetSdk 22 + 전체 화면 오버레이로 주행 중에도 앱 화면이 남습니다 (앱을 켜 둔 채 출발했을 때만).
- **주차 위치·주차 사진** — 기어를 P로 넣는 순간 위치 저장 + 차량 카메라 촬영 → 서버에 올려 폰에서 확인.
- **소모품 관리** — 타이어·브레이크 패드·필터·와이퍼·감속기 오일 교체 주기.
- **웹/폰 로그** — 기록을 Supabase(무료)에 올리고 `web/p4log-web.html`을 폰·PC 브라우저로 열어 조회 (모바일 UI).

## 구조

```
app/                      차량 앱 (Android Automotive OS, Kotlin, 외부 의존성 없음)
app/src/main/assets/map.html   차량 내 지도 (Leaflet + VWorld 타일)
web/p4log-web.html        웹/폰 로그 (단일 HTML, Supabase 직접 조회)
supabase/supabase_setup.sql    서버 테이블 생성 SQL
```

- 차량 데이터는 `android.car`를 **리플렉션**으로 읽습니다 → 일반 Android SDK로 빌드됩니다.
- 로컬 DB는 SQLite, 서버 동기화는 Supabase REST(PostgREST) upsert. 주행 중엔 서버를 부르지 않습니다.
- minSdk 22 / **targetSdk 22**(주행 중 오버레이를 위해 필요) / compileSdk 34 / Kotlin 1.9 / AGP 8.5.

## 설치 안내 (처음 하는 분 기준)

### 0. 준비물

| 항목 | 비고 |
|---|---|
| Windows/Mac PC + Android Studio | 최신 안정판. JDK 17 포함됨 |
| C타입 USB 메모리 | **FAT32**로 포맷 |
| Supabase 계정 (무료) | 웹/폰에서 기록을 보려면 필요. 차 안에서만 볼 거면 생략 가능 |
| VWorld 인증키 (무료) | 지도 타일용. 없으면 지도만 안 뜨고 나머지는 동작 |
| data.go.kr 인증키 (무료) | 충전소 자동 인식용. 없으면 충전소 이름만 안 잡히고 요금은 기본 단가로 계산 |

### 1. 키 3개 발급 (약 20분)

1. **Supabase**: https://supabase.com 가입 → **New project** (리전 Northeast Asia · Seoul) →
   왼쪽 **SQL Editor**에 `supabase/supabase_setup.sql` 전체를 붙여넣고 **Run** →
   **Project Settings → API**에서 `Project URL`과 `anon public` 키를 복사.
2. **VWorld**: https://www.vworld.kr 가입 → 오픈API → 인증키 발급 (서비스 URL은 아무 값이나, 예 `http://localhost`).
3. **공공데이터포털**: https://www.data.go.kr 가입 → "한국환경공단_전기자동차 충전소 정보" 활용신청 →
   마이페이지에서 **일반 인증키(Encoding)** 복사. 승인까지 몇 시간~하루 걸릴 수 있습니다.

### 2. 키 입력 — 빌드 없이 앱 안에서

키 4개는 모두 **앱 설정 탭**과 **웹 첫 화면**에서 입력합니다. 소스를 고칠 필요가 없습니다.

| 키 | 차량 앱 | 웹/폰 |
|---|---|---|
| Supabase URL · anon 키 | 설정 탭 "웹 로그 연동" | 첫 화면 |
| VWorld 키 | 설정 탭 "API 키" (지도·동네 이름) | 첫 화면 (선택) |
| data.go.kr 키 | 설정 탭 "API 키" (Encoding 키 그대로, 다시 인코딩하지 말 것) | 사용 안 함 |

직접 빌드한다면 `app/src/main/java/com/p4log/car/Prefs.kt`의 `DEFAULT_*` 상수와 `web/p4log-web.html` 맨 아래 `DEFAULT_CFG`에 기본값을 넣어 둘 수도 있습니다.

### 2-1. 빌드가 번거로우면 — 릴리즈 APK 사용

[Releases](https://github.com/dozyco/plog/releases)에 키와 개인 기록이 전혀 없는 APK 두 개가 있습니다.

- `plog-car.apk` — 차량용. 4단계대로 USB로 설치한 뒤 설정 탭에서 키를 입력하면 끝.
- `plog-mobile.apk` — 폰용(웹 로그 내장). 설치 후 첫 화면에서 URL·키·차량 ID 입력.

이 경우 3단계(빌드)는 건너뜁니다.

### 3. APK 빌드 (약 5분)

1. Android Studio → **Open** → 이 저장소 폴더 선택 → Gradle 동기화가 끝날 때까지 대기 (첫 회는 몇 분).
2. 메뉴 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
3. 완성 파일: `app/build/outputs/apk/debug/app-debug.apk` → 이름을 `p4log.apk` 정도로 바꿔 둡니다.

명령줄이 편하면:

```
gradlew assembleDebug
```

### 4. 차량에 설치 (USB 사이드로드)

1. USB를 FAT32로 포맷하고 `p4log.apk`를 복사합니다.
2. 콘솔박스 **오른쪽** C타입 포트에 USB를 꽂습니다.
3. 차량에서 파일 탐색기 앱(사이드로드용 USB 파일 탐색기가 있으면 그것)으로 USB의 `p4log.apk`를 열어 설치합니다.
   탐색기가 없으면 웨일 브라우저 → 네이버 메일 → 내게 쓰기 → 파일 첨부 → "내 PC"로 파일 탐색기를 여는 방법이 있습니다.
4. 애플리케이션 목록에 **P.Log**(주황 번개 아이콘)가 생기면 성공입니다.

> **targetSdk 22 앱은 기존 설치 위에 업데이트가 안 됩니다.** 새 버전을 올릴 때는 **삭제 후 재설치**하세요.
> 재설치하면 로컬 기록·설정(차량 ID 포함)이 지워집니다. 차량 ID를 웹/폰과 맞춰 쓰고 있었다면 설정에서 다시 입력하세요.

### 5. 첫 실행

1. 앱을 열면 권한 팝업이 뜹니다 → **전부 허용**. 위치는 **"항상 허용"**으로.
2. **설정 탭 → 차량 데이터 진단**: 배터리 잔량 / 순간 전력 / 주행가능거리 / 바퀴 틱이 **OK**인지 확인.
   적산거리(PERF_ODOMETER)와 타이어는 "권한 거부"가 정상입니다(시스템 전용).
3. 설정 탭에 **배터리 용량**(kWh)과 **현재 누적 주행거리**(계기판 값)를 넣고 **[설정 저장]**.
4. Supabase를 쓰면 URL·anon 키를 넣고 **[연결 테스트]** → "연결 성공 (200)" → **[지금 올리기]**.
   **차량 ID**는 자동 생성된 값을 그대로 쓰고, 웹/폰에서 같은 값을 입력하면 됩니다.

### 6. 웹/폰에서 보기

1. `web/p4log-web.html`을 폰이나 PC 브라우저로 엽니다 (로컬 파일로 열어도 동작. GitHub Pages·Cloudflare Pages 등에 올려도 됨).
2. URL / anon 키 / 차량 ID를 입력 → **불러오기**. 입력값은 주소창 `#` 뒤에 저장되므로 그 상태로 즐겨찾기하면 다음부터 바로 열립니다.
3. 아래 탭바 **주행 / 충전 / 차량**. 차량 탭에 주차 위치·주차 사진·소모품이 나옵니다.

### 동작 방식 (알아 두면 좋은 것)

- 4 km/h 이상으로 움직이면 주행 시작, 3분 정지 또는 시동 OFF면 종료. 300 m 미만은 기록하지 않습니다.
- 충전은 "정차 + 충전 포트 연결 + 전력 유입"일 때만 인식합니다 (회생제동을 충전으로 오인하지 않기 위해).
- 주행 중 화면(오버레이)은 **앱을 화면에 띄운 채 출발했을 때만** 나타나고, [닫기]를 누르면 다음에 앱을 열 때까지 뜨지 않습니다.
- 주차 사진은 **기어를 P에 넣는 순간** 찍습니다 (시동을 끈 뒤에는 차량 카메라가 영상을 주지 않음).
- 서버 업로드는 주차 중에만, 10분 간격입니다. 주행 중엔 차량에 부하를 주지 않습니다.
- 앱 안의 **설정 → 차량 데이터 진단** 아래에 서비스 이력이 남고, 동기화 때마다 Supabase Storage(`parking/<차량ID>-svclog.txt`)에도 올라갑니다.
  문제가 생기면 이 파일을 보면 원인을 알 수 있습니다.

### 문제 해결

| 증상 | 조치 |
|---|---|
| 배터리/전력이 전부 "권한 거부" | 차량이 서드파티에 차량 데이터를 안 열어준 경우. GPS 주행 기록·소모품은 계속 동작 |
| 주행이 기록 안 됨 | 위치 권한 "항상 허용" 확인, 진단에서 GPS 수신·바퀴 틱 확인 |
| 충전이 기록 안 됨 | 진단에서 "순간 전력"·"충전 포트" OK인지 확인 |
| 웹에서 데이터 안 보임 | 차량 ID가 앱 설정과 같은지, 설정 탭 [지금 올리기] 후 새로고침 |
| 연결 테스트 404 | `supabase_setup.sql`을 실행하지 않은 것 — SQL Editor에서 다시 Run |
| 지도가 안 뜸 | VWorld 키 입력 여부, 차량/폰 인터넷 연결 확인 |
| 충전소 이름이 "미확인" | data.go.kr 키 승인 여부 확인. 충전 기록에서 [충전소 직접 선택]으로 지도에서 고를 수 있음 |
