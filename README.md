# P.Log — 폴스타4 전기차 주행·충전 로그 (Android Automotive OS)

폴스타4 차량 화면에서 직접 동작하는 개인용 전기차 **주행·충전 로그** 앱입니다.
USB로 설치하며, 차량 앱은 외부 라이브러리 없이 플랫폼 API만으로 만들어졌습니다.

> 개인 프로젝트이며 폴스타·볼보와 무관합니다. 사용에 따른 책임은 사용자에게 있습니다.
> 이 저장소와 릴리즈 APK에는 **API 키와 개인 기록이 하나도 들어 있지 않습니다.** 아래 안내대로 본인 키를 만들어 앱에 넣으면 됩니다.

## 주요 기능

- **주행 자동 기록** — 기어를 D(또는 R)에 넣으면 시작, P에 넣고 1분이 지나면(또는 시동을 끄면) 한 번의 주행으로 저장. 바퀴 틱 기반 거리(터널·지하에서도 안 끊김), GPS 경로, 평균·최고 속도, 전비, 회생 회수량.
- **주행 탭** — 배터리·주행가능거리, 속도, 이번 주행 거리·전비, 실시간 전력 게이지, 충전 이후 사이클(달린 km·배터리 사용·회생 비율), 시계.
  주행 중엔 **지금 달리는 경로 라이브 지도**, 주차 중엔 이번 주·이번 달 요약과 오늘 타임라인·주행 기록 표로 바뀝니다. 마지막 주행이 평소 전비보다 좋았는지도 알려 줍니다.
- **주행 기록 화면** — 일간/주간/월간/연간/전체(마지막 선택 기억), 기간 요약, 출발 → 도착 동네 이름, 경로 지도(구간별 전비 색), 개인 최고 기록.
- **충전 자동 기록** — 충전 감지, kWh·요금 계산, 급속/완속 구분, 충전 타임라인(전력 곡선 + 열 띠), 기간 탭, 급속/완속 비율, **집·회사/외부 비율**, 충전 위치 동네 이름.
- **충전소 자동 인식 + 요금 자동** — 한국환경공단 충전소 OpenAPI로 충전소·운영사를 알아내고, 무공해차 통합누리집 공식 요금표를 앱 안에서 읽어 단가를 채웁니다.
  못 잡으면 **지도에서 직접 선택**(차량·폰 모두)할 수 있고, 한 번 고르면 다음부터 그 자리에서 자동 인식됩니다.
- **내 충전기(집·회사)** — 집이나 회사 충전기는 버튼 한 번으로 등록. 위치만으로 인식하고, 요금은 정액 단가 또는 **한전 전기차 충전 시간대 요금**(경부하·중간·최대 자동)으로 계산합니다.
  완속은 계량기 기준(배터리에 들어간 kWh ÷ 0.88)으로 요금을 셉니다.
- **주행 중 화면** — 앱을 켜 둔 채 출발하면 주행 중에도 앱 화면이 남습니다.
- **주차 위치·주차 사진** — 기어를 P로 넣는 순간 위치 저장 + 차량 카메라 촬영 → 폰에서 확인.
- **소모품 관리** — 타이어·브레이크 패드·필터·와이퍼·감속기 오일 교체 주기.
- **폰 앱 / 웹** — 기록을 Supabase(무료)에 올리고 폰 앱이나 브라우저에서 봅니다. 폰에서 단가·충전소를 고치면 차량에도 반영됩니다(양방향).
  서버를 얼마나 썼는지 막대로 보여 주고, 목록은 쪽수(1 2 3 4 5)로 넘깁니다.

# 설치 안내 (처음 하는 분도 그대로 따라 하면 됩니다)

전체 흐름은 이렇습니다. 시간은 넉넉히 1시간 잡으세요.

```
① 준비물 확인 → ② 서버(Supabase) 만들기 → ③ 지도 키 만들기 → ④ 충전소 키 신청하기
→ ⑤ 차량용 APK를 USB에 담기 → ⑥ 차에 설치하기 → ⑦ 차 안에서 권한 허용 + 키 입력
→ ⑧ 폰에 앱 설치하고 연결하기 → ⑨ 첫 주행 → ⑩ 충전 기록 다듬기
```

키 3개(②③④)는 전부 **무료**이고, 한 번만 만들면 됩니다. ④는 승인에 시간이 걸리니 **제일 먼저 신청해 두고** 다른 단계를 진행하세요.

이미 예전 버전을 쓰고 있었다면 맨 아래 **[업데이트하는 분]** 만 보면 됩니다.

## ① 준비물

| 준비물 | 설명 |
|---|---|
| 폴스타4 | 이 앱은 폴스타4 화면(Android Automotive OS)에서만 동작합니다 |
| Windows PC 또는 Mac | 파일을 내려받아 USB에 옮기는 데 씁니다 |
| USB 메모리 (C타입 또는 A타입 + C타입 변환 젠더) | **32GB 이하**를 권합니다. 64GB 이상은 Windows에서 FAT32 포맷 메뉴가 안 나옵니다 |
| 이메일 주소 | 회원가입 3곳에 필요합니다 |
| 안드로이드 폰 | 폰 앱용. 아이폰이면 폰 앱 대신 브라우저로 웹 파일을 열어 씁니다 (⑧-B) |

## ② 서버 만들기 — Supabase (약 10분)

기록을 올려 두는 곳입니다. 무료이고 신용카드가 필요 없습니다.

1. 브라우저에서 **https://supabase.com** 을 엽니다. 오른쪽 위 **Start your project** 를 누릅니다.
2. **Continue with GitHub** 또는 이메일로 가입합니다. (GitHub 계정이 없으면 이메일 가입 → 받은 메일의 확인 링크 클릭)
3. 로그인되면 **New project** (또는 **+ New project**) 버튼을 누릅니다.
   - **Name**: `plog` 라고 적습니다.
   - **Database Password**: 아무 비밀번호나 만들고 **메모장에 적어 둡니다** (다시 볼 일은 거의 없지만 잃어버리면 안 됩니다).
   - **Region**: **Northeast Asia (Seoul)** 을 고릅니다.
   - **Create new project** 를 누르고 1~2분 기다립니다.
4. 왼쪽 메뉴에서 **SQL Editor** (종이에 `SQL`이라고 쓰인 아이콘) 를 누릅니다.
5. 이 저장소의 `supabase/supabase_setup.sql` 파일을 엽니다.
   (GitHub 화면에서 `supabase` 폴더 → `supabase_setup.sql` 클릭 → 오른쪽 위 **Raw** 를 누르면 글자만 나옵니다. **Ctrl+A** 전체 선택 → **Ctrl+C** 복사)
6. Supabase SQL Editor의 빈 칸에 **Ctrl+V** 로 붙여넣고 오른쪽 아래 **Run** 을 누릅니다.
   아래에 **Success. No rows returned** 라고 나오면 성공입니다. 표 4개(trip, charge, parking, consumable)와 사용량 함수가 만들어집니다.
7. 이제 키 2개를 복사합니다. 왼쪽 메뉴 맨 아래 **톱니바퀴(Project Settings)** → **API Keys** (버전에 따라 **API**) 를 누릅니다.
   - **Project URL**: `https://xxxxxxxx.supabase.co` 모양 → 메모장에 **"서버 주소"** 라고 이름 붙여 복사해 둡니다.
   - **anon public** (버전에 따라 **publishable**) 키: `sb_publishable_...` 또는 `eyJhbGci...` 로 시작하는 긴 글자 → 메모장에 **"서버 키"** 로 복사해 둡니다.
   - `service_role` / `secret` 키는 **절대 쓰지 마세요**. 앱에는 anon(publishable) 키만 넣습니다.
8. 주차 사진을 쓰려면 저장소(Storage)도 하나 만듭니다. 왼쪽 메뉴 **Storage** → **New bucket** → 이름 `parking`, **Public bucket** 을 켜고 만듭니다.
   그다음 그 버킷의 **Policies** 에서 **New policy → For full customization** 으로 `anon` 역할에 **SELECT / INSERT / UPDATE** 를 허용합니다. (모르겠으면 이 단계는 건너뛰어도 됩니다. 사진만 안 올라갑니다.)

## ③ 지도 키 만들기 — VWorld (약 5분)

지도 타일과 동네 이름에 씁니다. 없어도 앱은 돌아가지만 지도가 비어 보이고 동네 이름이 안 나옵니다.

1. **https://www.vworld.kr** 에서 회원가입 후 로그인합니다.
2. 위 메뉴 **오픈API** → **인증키 발급** (또는 **인증키 신청**) 을 누릅니다.
3. 신청서를 채웁니다. 내용은 아무거나 괜찮습니다.
   - 서비스명: `plog`
   - 서비스 URL: `http://localhost`
   - 사용 목적: `개인 전기차 기록 앱`
4. 발급이 끝나면 **마이페이지 → 인증키 관리** 에 `XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX` 모양의 키가 보입니다.
   메모장에 **"지도 키"** 로 복사해 둡니다.

## ④ 충전소 키 신청하기 — 공공데이터포털 (신청 5분 + 승인 대기)

충전소 이름·운영사를 알아내고, 지도에서 충전소를 고를 때 씁니다. 없어도 충전 기록은 되지만 충전소 이름이 "미확인"으로 남고 요금은 기본 단가로 계산됩니다.

1. **https://www.data.go.kr** 에서 회원가입 후 로그인합니다.
2. 맨 위 검색창에 `한국환경공단_전기자동차 충전소 정보` 를 검색합니다.
3. 결과에서 같은 이름의 **오픈API** 항목을 열고 **활용신청** 을 누릅니다.
   - 활용목적: **웹 사이트 개발** 또는 **앱개발** 을 고르고 설명은 `개인 전기차 충전 기록 앱` 정도로 적습니다.
   - 아래 항목에 전부 체크하고 **활용신청** 을 누릅니다.
4. 승인은 보통 몇 시간, 길면 하루 걸립니다. 승인되면 **마이페이지 → 데이터활용 → Open API → 활용신청 현황** 에서 항목을 열고
   **일반 인증키 (Encoding)** 옆의 긴 글자를 메모장에 **"충전소 키"** 로 복사해 둡니다.
   - **Encoding** 키를 씁니다. Decoding 키가 아닙니다. 끝에 `%3D%3D` 같은 글자가 붙어 있는 게 정상입니다.

## ⑤ 차량용 APK를 USB에 담기 (약 10분)

### ⑤-1. APK 내려받기

1. 이 저장소의 **Releases** (https://github.com/dozyco/plog/releases) 페이지를 엽니다.
2. 맨 위 최신 릴리즈의 **Assets** 를 펼치고 **plog-car.apk** 를 눌러 내려받습니다.
   브라우저가 "이 파일은 해로울 수 있습니다"라고 물으면 **유지(계속)** 를 누릅니다. 사이드로드 APK는 원래 이런 경고가 뜹니다.

### ⑤-2. USB를 FAT32로 포맷 (Windows)

USB 안의 파일은 전부 지워집니다. 필요한 파일은 먼저 옮겨 두세요.

1. USB를 PC에 꽂습니다.
2. **파일 탐색기 → 내 PC** 에서 USB 드라이브를 **오른쪽 클릭 → 포맷** 을 누릅니다.
3. **파일 시스템**을 **FAT32** 로 고릅니다. (exFAT나 NTFS는 차에서 못 읽습니다.)
   - FAT32가 목록에 없으면 USB가 64GB 이상인 것입니다. 32GB 이하 USB를 쓰세요.
4. **빠른 포맷** 에 체크된 채로 **시작** 을 누릅니다.

Mac이면: **디스크 유틸리티** → USB 선택 → **지우기** → 포맷 **MS-DOS(FAT)**, 방식 **마스터 부트 레코드** → 지우기.

### ⑤-3. 파일 복사

1. 내려받은 `plog-car.apk` 를 USB의 **맨 바깥(루트)** 에 복사합니다. 폴더 안에 넣지 마세요.
2. USB를 **안전하게 제거** 한 뒤 뽑습니다.

## ⑥ 차에 설치하기 (약 5분)

1. 차 시동을 켭니다(주차 상태, P단).
2. USB를 **가운데 콘솔박스 안, 오른쪽 C타입 포트** 에 꽂습니다. (왼쪽은 충전 전용인 경우가 있습니다.)
3. 차량 화면에서 **파일을 열 수 있는 앱** 이 필요합니다. 둘 중 하나로 합니다.
   - **A. USB 파일 탐색기 앱이 이미 있으면**: 그 앱을 열고 USB → `plog-car.apk` 를 누릅니다.
   - **B. 없으면 (기본 방법)**: 차량의 **웨일 브라우저** 를 열고 **네이버 메일** 에 로그인 → **내게 쓰기** → **파일 첨부** 를 누르면 파일 선택 창이 뜹니다.
     왼쪽 메뉴에서 **내 PC**(또는 **USB 드라이브**) 를 고르고 `plog-car.apk` 를 **길게 누른 뒤** 나오는 메뉴에서 **열기** 를 누릅니다.
     (메일은 보내지 않아도 됩니다. 파일 선택 창을 여는 용도입니다.)
4. **"이 앱을 설치하시겠습니까?"** 창이 뜨면 **설치** 를 누릅니다.
   - "보안상의 이유로 출처를 알 수 없는 앱을 설치할 수 없습니다"가 뜨면 **설정** 을 누르고 **이 출처 허용** 을 켠 뒤 다시 설치합니다.
5. **"앱이 설치되었습니다"** 가 나오면 **열기** 를 누르거나, 앱 목록에서 **P.Log**(주황 번개 아이콘) 를 찾아 엽니다.

> **새 버전으로 올릴 때**: 같은 방법으로 새 `plog-car.apk` 를 열면 그 위에 덮어씌워지고 기록·설정은 그대로 남습니다.
> 만약 "앱이 설치되지 않았습니다"가 뜨면 기존 P.Log를 삭제하고 다시 설치하세요. 그 경우 차 안의 기록·설정은 지워지지만 서버에 올라간 기록은 남아 있습니다.
> 재설치 후 설정에서 **차량 ID를 예전 값으로 다시 입력**하면 폰에서 계속 이어서 볼 수 있습니다.

## ⑦ 차 안에서 권한 허용 + 키 입력 (약 10분)

### ⑦-1. 권한

앱을 처음 열면 허용 창이 여러 번 뜹니다. **전부 허용** 합니다.

| 뜨는 창 | 누를 것 |
|---|---|
| 위치 정보 액세스 | **앱 사용 중에만 허용** (다음 창에서 항상 허용으로 바꿉니다) |
| 백그라운드 위치 / "항상 허용하시겠습니까" | **항상 허용** ← 이게 제일 중요합니다. 없으면 앱을 안 켠 날 주행이 기록되지 않습니다 |
| 카메라 | **허용** (주차 사진용) |
| 차량 에너지 / 속도 / 파워트레인 정보 | **허용** |
| 알림 | **허용** |

"항상 허용" 창을 못 봤거나 실수로 거부했다면: 차량 **설정 → 앱 → P.Log → 권한 → 위치 → 항상 허용** 으로 바꿉니다.

### ⑦-2. 잘 읽히는지 확인

앱 아래쪽 **설정** 탭 → **차량 데이터 진단** 을 누릅니다.

- **배터리 잔량 / 순간 전력 / 주행가능거리 / 바퀴 틱 / 기어** 가 **OK** 면 정상입니다.
- **적산거리(PERF_ODOMETER)** 와 **타이어** 는 "권한 거부"가 **정상** 입니다. 폴스타가 일반 앱에 안 열어 주는 값입니다.
- 배터리·전력이 "권한 거부"면 뒤로 가서 권한 창을 다시 확인하세요. **[권한 다시 요청]** 버튼도 있습니다.

### ⑦-3. 키 입력

키가 길어서 차 안에서 직접 치기 힘듭니다. **추천 방법**: 메모장에 모아 둔 키 4개를 **네이버 메일 → 내게 쓰기** 로 보내 두고, 차 안 웨일 브라우저로 그 메일을 열어 키를 **길게 눌러 복사** → 앱 입력칸을 **길게 눌러 붙여넣기** 합니다.

**설정** 탭에서:

1. **왼쪽 "차량"**
   - **배터리 용량 (kWh)**: 폴스타4는 싱글모터·듀얼모터 모두 100 kWh 배터리라 `100` 그대로 둡니다. (듀얼모터의 400 kW는 모터 출력이지 배터리 용량이 아닙니다.)
   - **현재 누적 주행거리 (km)**: 계기판의 총 주행거리를 숫자만 입력합니다. (소모품 계산 기준)
2. **왼쪽 "API 키"**
   - **VWorld 지도 인증키**: ③의 **지도 키** 붙여넣기.
   - **충전소 정보 API 키**: ④의 **충전소 키** 붙여넣기. (아직 승인 전이면 비워 두고 나중에 넣어도 됩니다.)
3. **오른쪽 "웹 로그 연동"**
   - **Project URL**: ②의 **서버 주소** 붙여넣기.
   - **anon public 키**: ②의 **서버 키** 붙여넣기. (오른쪽 **보기** 를 누르면 글자가 보입니다.)
   - **차량 ID**: 앱이 자동으로 만든 `p4-123456` 같은 값입니다. **이 값을 사진 찍어 두거나 메모하세요.** 폰 앱에 똑같이 넣어야 합니다.
4. 아래 **설정 저장** 을 누릅니다.
5. **연결 테스트** 를 누릅니다. **"연결 성공 (200)"** 이 나오면 됩니다.
   - **404** 가 나오면 ②-6의 SQL을 실행하지 않은 것입니다. Supabase SQL Editor에서 다시 Run 하세요.
   - **401/403** 이면 서버 키를 잘못 붙여넣은 것입니다. anon(publishable) 키인지 확인하세요.
6. **지금 올리기** 를 누릅니다. "성공 (0 건)" 이면 정상입니다(아직 기록이 없으니까요).
7. 그 아래 **서버 사용량 · 무료 한도** 막대 두 개(데이터베이스 500 MB, 저장소 1 GB)가 채워지면 서버와 완전히 연결된 것입니다.

여기까지 하면 차 쪽은 끝입니다. 이제 차는 알아서 기록하고, 주차 중일 때 서버에 올립니다.

## ⑨ 첫 주행

1. 차에서 **P.Log를 연 채로** 출발해 보세요. 주행 중에도 화면이 남고, 아래쪽에 지금 달리는 경로가 그려집니다.
   (앱을 안 켜고 출발하면 화면만 안 뜰 뿐 기록은 됩니다.)
2. 기어를 **D**(또는 R)에 넣으면 기록이 시작되고, 도착해서 **P**에 넣고 **1분**이 지나거나 시동을 끄면 한 번의 주행으로 저장됩니다.
   신호 대기나 잠깐 멈춤은 같은 주행입니다. 잠깐 D/P를 왔다 갔다 한 것과 300 m 미만은 저장하지 않습니다.
3. 기어를 **P**에 넣는 순간 주차 위치가 저장되고 주차 사진이 찍힙니다. (사진은 시동이 켜진 상태에서 P에 넣을 때만 찍힙니다.)
4. 시동을 끄고 몇 분 뒤 폰 앱을 새로 열면 방금 주행이 보입니다. (차가 주차 중일 때 올리므로 바로 안 보이면 다음에 차를 켠 뒤 다시 확인하세요.)

## ⑩ 충전 기록 다듬기

충전은 케이블을 꽂으면 자동으로 기록됩니다. 충전소와 요금은 이렇게 정해집니다.

**공공 충전소 (마트·주차장·휴게소 등)**
1. 충전이 끝나면 앱이 충전소 키(④)로 근처 충전소 이름을 알아내고, 공식 요금표에서 그 충전소의 회원가를 읽어 단가를 채웁니다. 몇 분 걸릴 수 있습니다.
2. 이름이 "미확인"이거나 다른 충전소로 잡혔으면: 충전 기록을 열어 **[충전소 직접 선택]** 을 누르세요. 차량이 충전한 자리 주변 충전소가 지도에 번호로 뜹니다.
   번호를 누르면 이름·사업자·정격 출력과 공식 요금표 단가가 큰 숫자로 나옵니다. 숫자를 고칠 수도 있고, **[이 단가로 저장]** 을 누르면 끝입니다.
   한 번 고르면 다음부터 그 자리에서는 자동으로 인식됩니다. 폰 앱에서도 같은 방법으로 할 수 있습니다(**지도에서 충전소 선택**).
3. 영수증과 다르면 **[단가 수정]** 으로 실제 단가를 넣으세요. 그 충전소에 기억됩니다.

**집·회사 충전기 (공공 목록에 없는 곳)**
1. 그 자리에서 한 충전 기록을 열고 **[이 자리를 집으로]** 또는 **[이 자리를 회사로]** 를 누릅니다.
2. 요금 방식을 고릅니다.
   - **정액 단가**: 아파트 충전기 운영사 단가나 회사에서 정한 단가를 원/kWh로 입력합니다. 모르면 0.
   - **한전 전기차 충전 시간대 요금**: 집에 전기차 전용 계량기가 따로 있을 때. 밤(경부하)·낮(중간)·오후 2~5시(최대) 단가가 계절별로 자동 적용됩니다.
3. 저장하면 같은 자리의 지난 충전도 전부 집/회사로 바뀌고 요금이 다시 계산됩니다. 다음부터는 위치만으로 자동 인식됩니다.
4. 폰 앱에서도 같은 버튼이 있습니다(정액 단가만). 저장하면 차량이 다음 동기화 때 받아 갑니다.

**요금이 왜 실제보다 조금 적게 나오나요?**
- 앱은 배터리에 실제로 들어간 양(kWh)을 읽습니다. 완속 충전기의 계량기는 그보다 약 12% 많은 교류 쪽을 잽니다(차 안 충전기의 변환 손실).
- 그래서 집·회사 충전기는 요금을 **계량 kWh(배터리 kWh ÷ 0.88)** 로 계산하고, 상세 화면에 "계량 약 14.7 kWh (배터리 12.9 kWh)"처럼 둘 다 보여 줍니다.
- 공공 충전소는 영수증의 kWh와 단가로 **[단가 수정]** 을 한 번 해 두면 그 충전소에 기억됩니다.

| 주행이 기록 안 됨 | 위치 권한이 **항상 허용** 인지. 진단에서 **GPS 수신**·**바퀴 틱**·**기어** 확인 |

## 업데이트하는 분 (이미 예전 버전을 쓰고 있었다면)

1. **서버**: Supabase **SQL Editor** 에 아래를 붙여넣고 **Run** 합니다. 이미 있는 항목은 그냥 넘어가므로 여러 번 실행해도 괜찮습니다.

   ```sql
   alter table trip add column if not exists regen_kwh double precision;
   alter table trip add column if not exists start_place text;
   alter table trip add column if not exists end_place text;
   alter table charge add column if not exists edited_ts bigint;
   alter table charge add column if not exists st_lat double precision, add column if not exists st_lon double precision;
   alter table charge add column if not exists kind text;
   alter table charge add column if not exists place text;
   create or replace function plog_usage() returns json language sql security definer as $$
     select json_build_object(
       'db_bytes', pg_database_size(current_database()),
       'trips', (select count(*) from trip),
       'charges', (select count(*) from charge));
   $$;
   grant execute on function plog_usage() to anon;
   ```

2. **차량**: 새 `plog-car.apk` 를 ⑤~⑥대로 USB로 설치합니다. 기록·설정은 그대로 남습니다.
3. **폰**: 새 `plog-mobile.apk` 를 설치합니다. 첫 화면이 다시 뜨면 5칸을 채우고 **불러오기** 를 한 번 누르세요.

## 직접 빌드하려면 (개발자용)

1. Android Studio(최신 안정판)로 이 저장소 폴더를 엽니다.
2. 키를 소스에 미리 넣고 싶으면 `app/src/main/java/com/p4log/car/Prefs.kt` 의 `DEFAULT_SB_URL / DEFAULT_SB_KEY / DEFAULT_VWORLD_KEY / DEFAULT_DATA_GO_KEY` 와
   `web/p4log-web.html` 맨 아래 `DEFAULT_CFG` (u·k·d·v·g) 를 채웁니다. 비워 두면 앱 설정 화면에서 입력합니다.
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)** 또는 `gradlew assembleDebug`.
4. 산출물 `app/build/outputs/apk/debug/app-debug.apk` 를 ⑤-3부터 똑같이 진행합니다.

구조:

```
app/                           차량 앱 (Android Automotive OS, Kotlin, 외부 의존성 없음)
app/src/main/assets/map.html   차량 내 지도 (Leaflet + VWorld 타일, 키는 앱이 넘김)
shared/                        차량 앱·폰 앱 공용 코드 (공식 요금표 조회 FeeLookup)
web/p4log-web.html             웹/폰 로그 (단일 HTML, Supabase 직접 조회)
supabase/supabase_setup.sql    서버 테이블 생성 SQL
```

- 폰 앱은 `web/p4log-web.html` 을 WebView로 감싼 얇은 껍데기입니다. 이 저장소에는 껍데기 소스를 포함하지 않고 릴리즈 APK(`plog-mobile.apk`)만 제공합니다.
- 차량 데이터는 `android.car` 를 리플렉션으로 읽습니다 → 일반 Android SDK로 빌드됩니다.
- 로컬 DB는 SQLite, 서버 동기화는 Supabase REST(PostgREST) upsert. 주행 중엔 서버를 부르지 않습니다.
- minSdk 22 / targetSdk 22(주행 중 오버레이를 위해 필요) / compileSdk 34 / Kotlin 1.9 / AGP 8.5.
